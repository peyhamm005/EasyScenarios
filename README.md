# Easy Scenarios
All credits go to OpenRCT2/OpenScenarios!!!!! The only two things I changed is making it easier to add the scenarios to your game, and adding more scenarios for more OpenRCT2 fun. Here's how to do it.

# Instructions
Download the .zip you want from Releases. There are multiple. Choose wisely. (Or get all of them) Extract it and add everything in it to your OpenRCT2 scenarios folder. That's it. No need to go through every file individually.
